# فقاعة الإعلانات 🚫

تمنع الإعلانات اللي تطلع بنص الألعاب:
1. **حجب (VPN محلي للـ DNS):** طلبات شبكات الإعلانات (AdMob, Unity, AppLovin, ironSource…) تنرفض فالإعلان ما يتحمّل.
2. **الشاشة السودة (Accessibility):** إذا طلع إعلان رغم الحجب، يتغطى بشاشة سودة/بيضة مع ✕ ويحاول يدوس زر الإغلاق/التخطي بنفسه، ويكتم الصوت.
3. **الفقاعة:** دوسة = تشغيل/إطفاء الحجب.

- البناء تلقائي على GitHub Actions، والـ APK يطلع بـ **Releases**.
